# Data and code completeness audit

The v12-v16 evidence files already preserve effective inputs, accepted estimates, sensitivities, physical/controlled placement results, NA diagnostics and synthetic records. This audit additionally supplies the omitted original 1,896-group two-scale statistics table and accepted original outputs, the complete 53 native HOG tables, 30,528 original and 30,528 resolved included-family trees, 54 compressed aggregate orthology files, the 54-species rooted trees/concatenation group IDs, the full pinned code snapshot and the current funding-corrected manuscript.

The new file is research-reproducibility-supplement-20261028.zip in the same restricted, unpublished Zenodo draft 23723115. Its root manifest binds every retained file to size and SHA256. The native data are copied without rerunning alignment, gene-tree inference, STRIDE, reconciliation/HOG or pair export. All old archives remain. OG0000725 remains unresolved/excluded; all NA remain explicit. Tree rooting is conditional, not uniquely resolved.

This supplement has more than 2,000 members, so the old bounded verify_evidence.py catalog for v12-v14 intentionally does not cover it. Verify the whole ZIP against the server checksum, then use its root MANIFEST.json for file identities. A full CRC test can be requested with python -m zipfile -t on a separate copy; it is not a scientific computation. No full upstream raw Genome/GFF/RepeatMasker sources or all original alignments are repackaged here; their assembly/source references and known missing historical settings remain as documented. This package supports a substantially more complete input/results chain, while independent cross-environment numerical reproduction, licensing and formal access/publication remain separate.
