# Upstream inputs and scope

The resource contains 54 original species. Completed alignments, gene trees, species rooting, native reconciliation/HOG outputs and orthology pairs are reused. External dependencies include OrthoFinder 2.5.5, DIAMOND, MAFFT, FastTree and STRIDE; original inflation 1.5 is retained. Source/input hashes and executed parameters are supplied where retained. Unretained historical model, partition, trimming or executable settings remain explicitly unknown. Third-party implementations are not vendored or relicensed here.

Twelve STRIDE root candidates belong to the original topology. The primary conditional root and reference-topology/HOG scenarios remain distinct from a unique-root or independently validated species-tree claim. analysis/coordinates/bridge_adapter.py implements the project member bridge.

Coordinate support differs from callability and primary eligibility. Annotation indexing retains original complete gene bounds and all-exon masks. Genome materialization measures ACGT/non-ACGT and chromosome qualification. Canonical/row adapters retain source identity. Members, weights, species roster and tree/covariance choices are frozen before new repeat responses.

All NA, partial 5-prime evidence, conflicts, multiple locations, unresolved mappings and source-unavailable states are typed. Four source-response taxa retain nine NA anchor cells. The original full S35 summary stays NA; the separately defined P31 descriptive panel and failed interval-information gates remain separate. OG0000725 remains unresolved/excluded from the applicable HOG bridge in every scenario. Original discovery results and historical remote UNKNOWN are preserved.

This supplement expands code availability. Raw genomes/annotations and complete upstream native assets remain identified external inputs. Data access, missing historical settings, independent numerical reproduction and licensing are separate from syntax/source-identity checks.
